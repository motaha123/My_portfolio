I finished a computer science degree at Cairo University in 2025, focused on machine learning and computer vision. What I actually learned came after: building something people depend on, and discovering how different that is from a notebook that gets 94% on a held-out set.

The work I care about is retrieval — getting a model to answer from a source you can point at, rather than from whatever it absorbed in training. That constraint changes everything downstream: how you chunk the data, what you store as metadata, how you catch it when the source itself is wrong.

And sources are often wrong. One of the more instructive bugs I've fixed lived in nine curriculum files, not in the model and not in the renderer — equations were double-escaped at the source, so students saw raw LaTeX. Finding it meant refusing to accept that the layer in front of me was the guilty one.

Grownerd

A study assistant for the Syrian national curriculum. Ask it a question and the answer comes from the actual page of the actual textbook — not from a general model's recollection of what physics is.

Retrieval & models

  • 35 independent FAISS indexes, one per subject, built from textbook pages with lesson- and page-level metadata — so an answer can be traced to page 42 of tenth-grade algebra.
  • Generation on gpt-4o-mini, retrieval on text-embedding-3-large. Migrating generation down from gpt-4o cut cost per question to roughly $0.0006 without a quality drop worth the difference.
  • All 35 indexes preload into memory per worker, so retrieval doesn't pay disk cost on the request path.
  • Question numbering made deterministic in code rather than trusted to the prompt — a model at temperature 0.7 will not follow a formatting instruction every time, and eventually a student notices.

Serving it to real people

  • Flask API handling Supabase auth, atomic token billing, routing across all 35 subject modules, and per-endpoint rate limits.
  • A shared answer cache in Redis: the first student to open a page pays for the explanation, everyone after reads it.
  • Gunicorn tuned to 240 concurrent requests on a 4 GB box — the switch from sync to threaded workers alone was an eighty-fold difference.
  • Backend security pass closing proxy-IP trust, client-supplied privilege flags, and error leakage — plus a startup check that refuses to boot on unsafe configuration, because a security control that fails silently is worse than none.
  • Next.js web client and a Flutter mobile app against the same API, with LaTeX rendering and full right-to-left Arabic.
